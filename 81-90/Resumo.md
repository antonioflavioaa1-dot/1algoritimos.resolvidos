# Resumo — Exercícios 81 a 90

Neste grupo, comecei a aplicar estruturas de seleção. Aprendi a testar condições e executar comandos diferentes conforme o resultado, usando `se` e `senão`. Pratiquei operações com dígitos para gerar um verificador, identificar números pares ou ímpares e classificar valores como positivos, negativos ou nulos. Também usei decisões encaixadas para encontrar o maior entre três números, validar respostas de texto, escolher operações de uma calculadora e selecionar uma opção de planeta para calcular o peso correspondente.
